      Using Chapar

      Learn how to organize your work and send HTTP and gRPC requests with Chapar.

      Spaces
      Keep separate sets of collections, requests and environments
      Environments
      Variables, secret values and switching between servers
      Requests and Collections
      Create, organize and share requests, and set defaults per collection
      HTTP Requests
      Methods, params, bodies, auth, headers, responses and code generation
      gRPC Requests
      Reflection or proto files, metadata, TLS, streaming and examples
      Request Actions
      Chain requests, set environment values and extract response data
      Cookies
      A cookie jar per environment that you can browse and edit
      Variables and Functions
      Variable syntax, completion and built-in dynamic values
      Settings
      HTTP defaults, themes, editor, language servers and security
      Chapar

      A fast, private and offline API client for REST, gRPC and GraphQL.

      Latest release: v0.7.0
